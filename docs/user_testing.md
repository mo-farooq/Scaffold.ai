# Scaffold.ai — User Testing Framework

Framework for conducting repeatable user testing sessions with student developers to evaluate pedagogical effectiveness.

---

## Metric Capture Framework

During student testing sessions, record the following metrics:

1. **Task Completion & Duration**:
   - Time spent per milestone (minutes).
   - Number of reflection attempts per milestone.

2. **Reflection Success Rates**:
   - First-pass success rate (passed on attempt 1).
   - Hint utility rate (passed on retry after receiving a hint).

3. **Workflow Friction Points**:
   - Log any prompt confusion or scope ambiguity.
   - Track drop-off points (milestones where students stop).

---

## Session Feedback Protocol

At the conclusion of a session, collect qualitative feedback on:
* *"Did the AI explain the 'why' behind code decisions clearly?"*
* *"Were the trade-off explanations helpful?"*
* *"Did the reflective question help reinforce the concept?"*
